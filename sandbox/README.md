# AI Security Sandbox

An interactive playground for learning AI security through hands-on attack simulations.

## Features

### 🔓 Interactive Attack Labs
- **Chat Attack Simulator** - Break LLM instructions with prompt injection
- **Adversarial Image Attack** - Fool vision models with invisible perturbations
- **Data Poisoning Playground** - Corrupt training data and watch models fail

### 🎯 What You Can Do
- Try real AI attacks in a safe environment
- Understand how AI systems fail
- Learn defense strategies
- Build cybersecurity intuition

### 🛠️ Tech Stack
- Pure HTML/CSS/JavaScript (no frameworks)
- Canvas API for visualizations
- Cyber-aesthetic design with neon accents
- Fully responsive and GitHub Pages ready

## Getting Started

1. Clone the repository
2. Open `sandbox/index.html` in your browser
3. Start breaking AI systems!

## Deployment

This site is designed for GitHub Pages:
1. Push to your repository
2. Enable GitHub Pages in settings
3. Select main branch as source
4. Your sandbox will be live!
