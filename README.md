# Ako Baloyi - Personal Portfolio

A fully responsive, dark minimalist portfolio website built with pure HTML, CSS, and JavaScript.

## Features

- **Dark Minimalist Design** with violet/cyan accents
- **Particle Animation** background on hero section
- **Smooth Scroll Animations** with Intersection Observer
- **Rotating Quotes** in Mindset section
- **Responsive Navigation** with mobile hamburger menu
- **Interactive Project Cards** with hover effects
- **Contact Form** with validation
- **Easter Eggs** (click the lock icon in footer 3 times!)
- **Fully Responsive** - works on all devices (320px+)
- **Fast Loading** - optimized for performance
- **GitHub Pages Ready** - no build process required

## Quick Start

1. Clone or download this repository
2. Open `index.html` in your browser
3. That's it! No installation or build process needed.

## Deployment to GitHub Pages

1. Create a new repository on GitHub
2. Push this code to the repository
3. Go to Settings → Pages
4. Select "main" branch as source
5. Your site will be live at `https://yourusername.github.io/repository-name`

## Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --bg-primary: #0E0E10;
    --accent-violet: #6C63FF;
    --accent-cyan: #70E0FF;
}
```

### Content
- Update text in `index.html`
- Replace project cards with your own projects
- Add your social media links
- Update the CV download link

### Fonts
Currently using:
- **Space Grotesk** for headings
- **Inter** for body text

Change in the Google Fonts link in `index.html`.
