# Product Overview

**Ako Baloyi - Personal Portfolio Website**

A dark minimalist portfolio website showcasing personal projects, mindset, and professional identity. The site emphasizes intentionality, curiosity, and technical craftsmanship through interactive design elements.

## Core Features

- Particle animation background with canvas rendering
- Rotating inspirational quotes
- Interactive project showcase cards
- Smooth scroll animations using Intersection Observer
- Mobile-responsive navigation with hamburger menu
- Contact form with validation
- Easter eggs (footer lock icon, Konami code, console messages)
- Performance-optimized with no external dependencies

## Design Philosophy

- **Dark minimalist aesthetic** with violet (#6C63FF) and cyan (#70E0FF) accent colors
- **Intentional interactions** - every animation and effect serves a purpose
- **Performance-first** - lightweight, fast loading, no frameworks
- **Accessibility** - responsive design supporting devices from 320px+
- **Personal branding** - reflects values of discipline, curiosity, and craftsmanship
