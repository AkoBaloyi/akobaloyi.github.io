Things I've Built

Enterprise Systems

Himpela, Field Asset Inspection Platform

Offline-first mobile inspection system for field technicians. Built with Go (Chi router), Flutter, PostgreSQL with row-level security, and S3 for media. Handles sync conflicts, tamper-evident audit trails, and works without connectivity.

The hard part was the trust layer: how do you prove an inspection actually happened, at that location, by that person? Solved it with temporal constraints, exponential backoff sync, and a local SQLite queue that reconciles against the server.

Production-ready offline-first platform with verifiable inspection records.

Email Breach Checker, C++ CLI Tool

Command-line tool that checks whether an email has appeared in known data breaches via the HaveIBeenPwned API. Written in C++17 with libcurl for HTTPS, nlohmann/json for parsing, and proper error handling for rate limits and auth failures.

Small project, but it shows I can work in C++ outside of coursework, handle real APIs with proper security (env-based key management, HTTPS only), and ship something useful as a standalone binary.

Working CLI tool, checks breaches in seconds.

Full-Stack Game

Morabaraba, Web-Based Game Platform

Browser-based implementation of the traditional Morabaraba board game with local play, AI opponents at multiple difficulty levels, online multiplayer via WebSockets, and an Elo rating system. Node.js + Express backend, vanilla JS frontend.

The interesting engineering was the game engine: deterministic state management, move validation, mill detection, and capture logic, all separated cleanly from the rendering layer so the same engine drives both the AI and the multiplayer server.

Playable in-browser with AI and online multiplayer.
